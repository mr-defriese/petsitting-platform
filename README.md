# petsitting-platform

Full-stack pet sitting booking platform with client portal and admin dashboard.

## Tech Stack
- Next.js (App Router) + TypeScript
- Tailwind CSS
- Supabase (Auth + Postgres)
- Vercel (deployment)

## Features (planned)
- Client portal: login, pet profiles, booking requests
- Admin dashboard: manage bookings, block availability
- Availability calendar
- Contact/request form (email)
